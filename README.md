# ☕ Starbrew Café Website

### A Little Coffee, A Lot of Comfort! 🌿

## 📌 About the Project

Starbrew Café is a responsive website developed for a local café business.
The website provides customers with information about the café, its menu,
prices, and contact details.

The main objective of this project is to help local businesses improve
their online presence and connect with more customers.

## 🎯 Objectives

- Create an attractive and user-friendly café website.
- Display the café menu and prices.
- Provide business information and contact details.
- Make the website accessible on mobile phones and computers.
- Help local businesses reach potential customers online.

## ✨ Features

- 🏠 Home section with an attractive introduction.
- ☕ Menu section displaying food and beverages.
- 🌿 About section describing the café.
- 📍 Contact section with location and opening hours.
- 💬 WhatsApp contact button.
- 📱 Responsive design for mobile and desktop.
- 🎨 Modern design with colours and typography.
- 🔗 Navigation links for easy browsing.

## 🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive layout.
- JavaScript – Interactive features.
- GitHub – Source code management.
- GitHub Pages – Website hosting.
